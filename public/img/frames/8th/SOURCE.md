# Eighth Edition frame assets

The ordinary frames, power/toughness plates, and masks were copied from the local [Card Conjurer](https://github.com/joshbirnholz/cardconjurer) clone at `D:\www\cardconjurer`, revision `d3c6706692898d596ec6a5be0be44f63062c9e12`. Geometry and asset choices follow `js/frames/pack8th.js`; dual-color composition follows `js/autoFrame.js`. The Matrix Bold fonts in `src/assets/fonts/matrix-b.ttf` and `matrix-bsc.ttf` came from the same clone. Nyx, crowns, border overlays, and other special layouts are excluded.

The clone has no explicit license file for these assets. Its `legal/index.html` says Magic-related material belongs to Wizards of the Coast and is intended for personal, non-commercial use. This note is attribution, not a license grant.
