# Neon Ink

Copied from local CardConjurer `img/frames/neonInk/{color}.png` and
`pt/{color}.png`, listed in `js/frames/packNeonInk.js`.
Base W/U/B/R/G/M/A/C/L variants only; no custom Transform/textless variants.
P/T assets are full-canvas overlays, drawn at original proportions while
the P/T text and debug region use the actual box. Dual colors use Multicolored.
This renders the graphic treatment, not the physical fluorescent foil effect.
