# Double Feature Transform

Shared front/back frames copied from local CardConjurer
`img/frames/doubleFeature/transform/{color}.png` and matching
`img/frames/doubleFeature/pt/{color}.png`, listed in
`js/frames/packDoubleFeatureTransform.js`.

W/U/B/R/G/M/A/L frames use regular front composition masks on both faces.
The pack lists a Land P/T asset that is absent; Land uses Artifact P/T.
Defaults are sun (front) and moon (back), with reverse P/T on front only.
Use the existing grayscale artwork toggle for the monochrome treatment.
